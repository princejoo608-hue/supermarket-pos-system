# Ajimi POS — نظام إدارة السوبر ماركت (سوبر ماركت البركة)

نظام نقاط بيع كامل لإدارة سوبر ماركت، مبني بـ PHP 8 + MySQL (PDO) + Bootstrap 5.

## المتطلبات
- XAMPP (PHP + MySQL + Apache)

## خطوات التركيب

### 1. نسخ المشروع
انسخ مجلد `supermarket-system` كاملاً إلى:
```
C:\xampp\htdocs\supermarket-system
```

### 2. تشغيل XAMPP
شغّل Apache و MySQL من XAMPP Control Panel.

### 3. استيراد قاعدة البيانات (خطوة واحدة فقط)
1. افتح `http://localhost/phpmyadmin`
2. من الصفحة الرئيسية مباشرة، دوس تبويب **Import**
3. اختر ملف `database/supermarket_db.sql`
4. دوس **Go**

الملف بينشئ قاعدة `supermarket_db` تلقائياً بكل الجداول والبيانات التجريبية - لا حاجة لأي خطوة يدوية إضافية.

### 4. فتح النظام
```
http://localhost/supermarket-system
```

## المزايا
- شاشة بيع (POS) سريعة: بحث فوري، فلترة تصنيف، منتجات مفضلة، خصم، دفع متعدد بفاتورة واحدة
- ترقيم فواتير عام + يومي (يبدأ من 1 كل يوم)
- إدارة: منتجات، تصنيفات، عملاء، موردين، مستخدمين (Admin/Cashier)، طرق دفع غير محدودة
- مرتجعات مع تحديث تلقائي للمخزون
- تقارير بفلاتر متعددة + تصدير CSV (Excel) + طباعة
- فاتورة حرارية 58mm/80mm قابلة للتخصيص من الإعدادات
- إعدادات عامة: اسم السوبر ماركت، الشعار، العملة، رسالة الفاتورة
- صفحة "عن النظام" (بيانات المطوّر Ajimi Systems - تظهر هنا فقط، غير مطبوعة بالفاتورة)
- تصميم بريميوم (برتقالي/أبيض، تأثيرات زجاجية، أنيميشن سلس) متجاوب مع الشاشات واللمس

## هيكل المشروع
```
supermarket-system/
├── config/database.php       ← الاتصال بقاعدة البيانات (PDO)
├── includes/                 ← header, footer, auth_check, functions
├── auth/                     ← تسجيل الدخول/الخروج
├── categories/                ← تصنيفات المنتجات
├── products/                 ← المنتجات (إضافة/تعديل/عرض/بحث)
├── customers/                 ← العملاء
├── suppliers/                 ← الموردين
├── users/                     ← المستخدمين (مدير فقط)
├── payment_methods/           ← طرق الدفع (مدير فقط)
├── sales/                     ← شاشة البيع، معالجة البيع، الفاتورة
├── refunds/                   ← المرتجعات
├── reports/                   ← التقارير والفلاتر
├── settings/                  ← الإعدادات + صفحة عن النظام
├── assets/css/style.css       ← التصميم
├── assets/uploads/            ← صور المنتجات والشعار
├── database/supermarket_db.sql   ← قاعدة البيانات كاملة + بيانات تجريبية
└── index.php                  ← لوحة التحكم الرئيسية
```

## ملاحظة أمنية مهمة
كلمات المرور مخزّنة **مشفّرة (bcrypt)** وليست نص عادي - هذا معيار أساسي لحماية أي نظام من الاختراق، حتى لو كان يعمل محلياً (Offline).
